# Low-Level Fundamentals (C)

This repository serves as a technical journal for my journey into the core of computer science. The goal is not merely to learn C syntax, but to understand how software interacts with hardware, how memory is managed, and how to optimize resources for high-performance computing.

## 🎯 Learning Objectives
- **Data Representation:** Understanding bytes, endianness, and overflow/underflow.
- **Memory Management:** Mastering the stack vs. heap and manual allocation.
- **Pointers:** Deep dive into memory addressing and pointer arithmetic.
- **Performance:** Analyzing low-level efficiency to build scalable software.

## 🛠️ Tech Stack
- **Language:** C (C11/C17 Standard)
- **Compiler:** GCC / Clang
- **Environment:** [e.g., WSL2 / Ubuntu / MacOS]

## 📂 Repository Structure
- `/01-memory-and-types`: Exploration of primitive types, bit-width, and memory sizing.
- `/02-control-flow`: Logic branching and memory jumps.
- `/03-pointers-and-addresses`: Mastering references and RAM interaction.
